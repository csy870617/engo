# AI 튜터 이미지·영상

튜터마다 폴더 하나에 아래 3개 파일을 올려 주세요. (GitHub에서 폴더를 연 뒤 **Add file → Upload files**)

| 파일 | 내용 |
|---|---|
| `base.png` | 기본 사진 (세로 3:4, 정면, 입 다문 미소) |
| `idle.mp4` | 듣는 영상 (숨쉬기·눈 깜빡임·살짝 끄덕임, 입은 닫힘, 6~10초 반복) |
| `talk.mp4` | 말하는 영상 (자연스럽게 말하는 입 모양, 6~10초 반복) |

- `emma/` : 여자 튜터 Emma
- `jay/` : 남자 튜터 Jay

두 영상은 같은 사진(`base.png`)으로 만들어야 해요. 카메라 고정, 손이 화면에 나오지 않게, 첫 장면과 마지막 장면의 자세를 같게.
파일이 크면(영상 하나 3MB 이상) 앱에 연결할 때 휴대폰용으로 줄여요.
